## 1. System Pipeline Overview

```
 Plain Text Certificate (.txt)
              │
              ▼
   [MODULE 1] Certificate & Record Management
        (records/database.py & parser.py)
              │
              │  Passes validated dict
              ▼
   [MODULE 2] SHA-256 Hashing Engine
        (hashing/hasher.py & canonicalizer.py)
              │
              │  Returns 64-char Hex SHA-256 Digest
              ▼
   [MODULE 3] Merkle Tree Builder
        (merkle/tree.py & proof.py)
              │
              │  Outputs Merkle Root & Proof Paths
              ▼
   [MODULE 4] Block Chaining
        (chain/chain.py & models.py)
              │
              │  Wraps in Block & Validates Linkage
              ▼
   [FLASK DASHBOARD & VERIFICATION]
```

## 2. Module Interface Contracts & Integration Points

### 2.1 Module 1 $\rightarrow$ Module 2 Interface
- **Function Called:** `chaincert.hashing.hash_certificate(cert_data: Dict[str, Any]) -> HashResult`
- **Payload Passed:** Dictionary containing `certificate_id`, `student_name`, `roll_number`, `course`, `cgpa`, `issue_date`, `institution_id`.
- **Returned Object:** `HashResult` dataclass containing `canonical_data` and 64-character hexadecimal `certificate_hash`.
- **Storage:** Module 1 stores `certificate_hash` in `certificates` table in SQLite.

### 2.2 Module 2 $\rightarrow$ Module 3 Interface
- **Function Called:** `chaincert.merkle.build_merkle_tree(leaf_hashes: Sequence[str]) -> MerkleTree`
- **Payload Passed:** List of 64-character hex strings generated by Module 2 (`leaf_hashes`).
- **Returned Object:** `MerkleTree` frozen dataclass containing `levels` and `merkle_root`.
- **Proof Generation:** `generate_proof_for_hash(tree, cert_hash) -> list[ProofStep]`. Serialized to JSON text via `proof_to_dicts()` and stored in SQLite.

### 2.3 Module 3 $\rightarrow$ Module 4 Interface
- **Function Called:** `chain_instance.add_batch(batch_id: str, merkle_root: str, certificate_count: int) -> Block`
- **Payload Passed:** `batch_id` (e.g. `SEM1_2026`), `merkle_root` (from `tree.merkle_root`), and `certificate_count`.
- **Returned Object:** `Block` frozen dataclass with `block_id`, `previous_root` (auto-linked to previous block's `merkle_root`), and `block_hash` (header SHA-256 digest).

## 3. End-to-End Python Code Example

```python
from chaincert.records import parse_certificate_file, add_certificate, assign_batch_and_proofs
from chaincert.merkle import build_merkle_tree, generate_proof_for_hash, proof_to_dicts
from chaincert.chain import Chain

# Step 1 & 2: Parse & Register via M1 & M2
c1 = add_certificate(parse_certificate_file("test_certificates/certificate1.txt"))
c2 = add_certificate(parse_certificate_file("test_certificates/certificate2.txt"))

# Step 3: Build Merkle Tree via M3
leaf_hashes = [c1["certificate_hash"], c2["certificate_hash"]]
tree = build_merkle_tree(leaf_hashes)

# Step 4: Generate proofs
proof1 = generate_proof_for_hash(tree, c1["certificate_hash"])
assign_batch_and_proofs("SEM1_2026", tree.merkle_root, {c1["certificate_id"]: proof_to_dicts(proof1)})

# Step 5: Append to Block Chain via M4
chain = Chain()
block = chain.add_batch(batch_id="SEM1_2026", merkle_root=tree.merkle_root, certificate_count=2)

# Step 6: Validate Chain
validation = chain.validate_chain()
print("Chain Validated:", validation.is_valid)
```
