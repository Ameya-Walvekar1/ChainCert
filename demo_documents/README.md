# Synthetic demo documents

All files in this directory are generated, fictional demonstration documents and are not official credentials.

- `CC001_original.pdf`: text-based PDF matching seeded certificate `CC001`.
- `CC001_modified.pdf`: same ID but CGPA changed from 9.20 to 9.99; expected `TAMPERED`.
- `CERT-A1_scanned.pdf`: image-only/scanned PDF for OCR demonstration; seeded as a separate synthetic credential so it can be verified end-to-end.

The OCR sample uses intentionally simple, high-contrast text. Real certificates may have different layouts and OCR errors; uncertain extraction should be reviewed rather than treated as proof of tampering.
