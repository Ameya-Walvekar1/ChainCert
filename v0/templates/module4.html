MODULE 4: Block Chaining

Lightweight Hash Chaining, Batch Linkage & Block Header Tamper Detection

🔗 What is Module 4?

Module 4 acts like an unalterable digital ledger. It takes the Merkle Root computed in Module 3 for a batch of student certificates and seals it inside a Block.

⛓️ How does Block Chaining work?

Every new block stores the Previous Block's Merkle Root as a link (previous_root). This links Block 1 ➔ Block 2 ➔ Block 3 in a continuous chain.

🛡️ How is Tampering Caught?

If anyone changes a student's grade in Block 1, Block 1's Merkle Root changes $\rightarrow$ Block 2's previous_root link breaks $\rightarrow$ CHAIN STATUS: INVALID!
